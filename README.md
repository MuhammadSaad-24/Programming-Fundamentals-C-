## 🧠 Topics Covered

### 1. Basic Coding

The initial tasks focus on understanding the fundamentals of programming.

Topics include:

- Variables and data types
- Input and output
- Operators
- Basic calculations
- Expressions
- Type conversions
- Writing simple programs

---

### 2. Problem Solving

A major focus of the course was learning how to approach programming problems logically.

The tasks involve:

- Understanding a problem
- Breaking problems into smaller steps
- Developing algorithms
- Converting logic into code
- Testing solutions
- Handling different input cases

---

### 3. Logic Building

The repository contains various problems designed to improve programming logic and analytical thinking.

These include problems involving:

- Conditions
- Loops
- Nested loops
- Number manipulation
- Digit-based problems
- Mathematical logic
- Counting and searching
- Repeated operations
- Pattern-based logic

---

### 4. Shapes & Patterns

Pattern and shape problems were used to strengthen logical thinking and understanding of nested loops.

Examples include:

- Squares
- Rectangles
- Triangles
- Pyramids
- Inverted patterns
- Hollow shapes
- Number patterns
- Character patterns
- Custom shapes

These problems focus heavily on controlling:

- Rows
- Columns
- Spaces
- Characters
- Nested iterations

---

### 5. Arrays

Arrays introduced working with collections of data instead of individual variables.

Problems include:

- Array input and output
- Searching
- Sorting
- Finding maximum and minimum values
- Counting elements
- Reversing arrays
- Duplicate handling
- Frequency-based problems
- Array manipulation
- Combining and comparing arrays

---

### 6. Character Arrays

Character arrays were used to solve problems involving text and individual characters.

Topics include:

- Character manipulation
- Character searching
- Counting characters
- Comparing character arrays
- Reversing character arrays
- String-like operations
- Character frequency problems
- Palindrome problems

---

### 7. Matrices

Matrix manipulation introduced more complex problems involving two-dimensional arrays.

Problems include:

- Matrix input and output
- Matrix traversal
- Row and column operations
- Matrix addition
- Matrix subtraction
- Matrix multiplication
- Transpose
- Diagonal operations
- Searching within matrices
- Matrix manipulation
- Two-dimensional array problems
